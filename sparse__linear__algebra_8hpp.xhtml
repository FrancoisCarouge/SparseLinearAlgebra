Detailed Description

Compile-time sparsity pattern linear algebra.

The positions of the stored elements are part of the matrix type. Every other element is a structural zero: it occupies no memory and costs no operation. Each operation computes the pattern of its result, and the exact arithmetic terms it needs, at compile time. There is no memory allocation, no exception, no input-output, and every operation is constexpr. A pattern without a structural zero behaves as any dense storage.

Note
Freestanding compatible. The formatting support requires a hosted implementation.
A structural zero stays an exact zero: no term exists for it. Unlike a dense computation, a non-finite operand does not propagate through it, for example 0 * infinity is never computed, and is not a not-a-number value.
