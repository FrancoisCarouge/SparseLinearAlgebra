Detailed Description

template<std::size_t Rows, std::size_t Columns, std::size_t Count>
struct fcarouge::sparse::pattern< Rows, Columns, Count >

The positions of the stored elements of a matrix.

A structural type, usable as a template argument, of strictly ascending row-major positions: two equal patterns are one and the same type of matrix, and a stored element's index is its rank among the positions. Prefer make_pattern, generate, and the named patterns, which establish that order.

Template Parameters
