template<typename Matrix , typename... Values>
requires sparse_linear_algebra::internal::is_matrix<Matrix> && (sizeof...(Values) == Matrix::structure.rows * Matrix::structure.columns) && sparse_linear_algebra::internal::are_given<Matrix, Values...>
auto fcarouge::sparse::make_matrix ( const Values &... values) -> Matrix
nodiscardconstexpr

A matrix from a value at every position, in row-major order.

Each position is known at compile time, and the type of each value says what it is: a value for a structural zero, even a zero, or 0_o for a stored element, does not compile. A run-time value needs no run-time check.

Template Parameters

ValuesThe types of the values.
Parameters
valuesThe value of each position, in row-major order: a value implicitly convertible to the element type at a stored element, the 0_o literal at a structural zero.
Complexity
Linear in the count of positions.
