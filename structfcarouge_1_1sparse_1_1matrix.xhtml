Detailed Description

template<typename Type, sparsity_pattern auto Pattern>
struct fcarouge::sparse::matrix< Type, Pattern >

Compile-time sparsity pattern matrix.

Stores only the elements of the pattern, in row-major order, in place. Every other element is a structural zero: it occupies no memory and costs no operation. A read of a structural zero yields a zero value. A structural zero has no element to refer to, so no write can reach it and no value can be lost: a write to a structural zero does not compile. A pattern without a structural zero behaves as any dense storage.

Read the element at the given compile-time position, by value.

A structural zero reads as a zero of the element type. Selected for a structural zero of a modifiable matrix too: the read is a value, not a reference, so that an assignment to the element of an arithmetic type, a write that would be lost, does not compile.
